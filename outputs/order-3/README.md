# ORDER//3

3人の固有カードを混ぜた共有デッキで戦う、部隊制デッキ構築タクティクスの最小プレイアブル試作です。

## 起動方法

`index.html` をブラウザで開いてください。ゲームの起動にインストールや通信は不要です。感想メモを継続して保存する場合は、同じブラウザから公開サイトなどの同じHTTP(S)アドレスを使ってください。ファイルを直接開いた場合の保存可否や範囲はブラウザによって異なります。

## 今回検証すること

- 敵の予告を見て、3枚の命令を組む判断が面白いか
- キャラクター固有カードが部隊内で役割を持てているか
- すべてのカードを移動に変換できることで、手札事故を防げるか
- 追跡・防御・詠唱という敵の組み合わせに複数の対処方法があるか

## 操作

1. 手札からカードを選択します。
2. 盤面上で対象を選択します。
3. 最大3枚まで命令を登録します。
4. 「作戦実行」で敵味方の行動を速度順に解決します。

画面下部の「ACTION ORDER」は、登録した味方の命令と敵の予告を実際の実行順へ統合したタイムラインです。左から順に処理され、実行中は現在の行動が強調表示されます。命令のない味方は「待機」として表示されます。

命令を1枚以上登録すると、盤面・HP・装甲・結界・印・移動不能・露出・帯電・罠・災印を全行動後の状態へ予測表示します。タイムラインの行動をクリックするとその行動直後へ切り替わり、「最終予測」で全行動後へ戻れます。射程外、対象撃破済み、移動先占有、詠唱解除など、実行前に分かる取消もタイムラインへ理由つきで表示します。作戦実行はこの予測と同じ解決結果を順番に適用します。

生存ユニットの状態は、駒の下部に`装甲・結界・移動不能 / 標的・露出・帯電`の固定3列×2段で表示します。装甲と帯電は現在値を省略せず、結界は駒の二重輪郭でも示します。駒へポインターを重ねる、キーボードでマスへフォーカスする、または状態面をタップすると、盤面直下で有効な状態の効果・消費条件・持続時間を確認できます。状態面のタップは説明だけを固定し、その一回を対象確定や移動には使いません。

各カードには、印刷された効果を探すための`攻撃・防御・機動・妨害・罠`の用途札があります。太枠と塗りのある札が主用途、`＋`と破線の札が副用途です。例えば「踏み込み斬り」は`攻撃＋機動`、「縫い留め」は`妨害＋攻撃`、「狩人の印」は`妨害：印`、「火種の罠」は`罠＋妨害`です。用途はカードの検索を助ける表示であり、効果・対象・速度・手札順を変更しません。全カード共通の`ALT：味方を1マス移動`は印刷効果の機動用途とは別です。移動命令へ切り替えた選択カードは`使用中：移動命令`を示し、現在の技法または遺志の分類を`元の用途`として残します。持ち主が戦闘不能なら、分類も現在表示される遺志へ置き換わります。

カード選択後に「移動命令に変換」を押すと、任意の味方を1マス移動できます。
命令キューへ移動を追加すると、駒は計画後の位置へプレビュー表示されます。「踏み込み斬り」「割って入る」「離脱射撃」「位相交換」など、固有技に含まれる移動も順番に仮計算します。続くカードの射程と対象判定もその位置から計算されるため、「1手目で移動、2手目で攻撃」という命令を組めます。「1手戻す」で仮位置も元へ戻ります。

距離と隣接は『ファイアーエムブレム』と同じ上下左右のマス数で計算します。斜めのマスは隣接扱いになりません。「踏み込み斬り」で斜め位置の敵を選べる場合は、攻撃前に上下または左右へ1マス踏み込み、上下左右に隣接してから攻撃します。

詠唱師の災印は、予告カードに座標で示されたマスへ固定されます。対象に見えたユニットが移動しても追尾しません。「柄打ち」が解除するのは、そのターンのタイムラインに存在する詠唱だけです。城壁兵の反撃姿勢による装甲は城壁兵の次の行動開始まで残り、反撃は実際に上下左右へ隣接している攻撃者だけを対象にします。

「火種の罠」は、射程3の空きマスに設置します。敵が踏むと3ダメージを与えて消滅し、その敵が現在解決中の移動イベントの残り歩数を失います。移動不能状態は付与せず、敵行動全体や別の後続移動イベントは取り消しません。停止後に予告対象へ上下左右に隣接していれば、移動後攻撃と付随効果は通常どおり解決します。

## 感想メモ（ACT 13）

上部の「感想メモ」から、感想・改善案・不具合を記録できます。本文を入力して約500ms後に、このブラウザへ下書きを自動保存します。「端末に保存」で即時保存でき、保存したメモの「編集」から同じメモを更新できます。再読込や再戦でも残ります。空白だけの本文は新しい保存件数に含めません。既存メモの本文を空にしても、以前の保存内容は削除しません。

「この場面を添付」は任意です。開いた時点のTURN、選択カード、最大3命令、予測段階、版名「ACT 13」だけを添えます。保存した場面は「現在の場面に更新」を押すまで変わりません。メモを開閉してもカード選択や命令はそのままで、作戦解決中も通常どおり処理が進みます。勝敗画面からも同じ上部ボタンを利用できます。キーボードではTabで移動し、Escapeで閉じると元のボタンへ戻ります。

端末への保存だけでは制作側へ送信されません。共有したい一件の「制作に送る ↗ GitHubで確認」を押すと、[ORDER//3の新規Issue画面](https://github.com/usouso/order-3/issues/new)を開きます。投稿すると公開されます。GitHubで内容を確認し、必要ならログインして、最後の投稿操作を行ってください。画面を開いただけでは投稿完了になりません。ゲームに認証情報を入力する必要はありません。

長文も切り捨てず保存します。共有URLが長い場合は本文を自動入力せず、全文コピーと「このメモをMarkdownで書き出す」を利用できます。タイトルだけ入ったGitHub画面へ全文を貼り付けてください。コピーや書き出しを使えない場合も、選択可能な全文欄から救済できます。

端末へ保存できない場合は本文をこのタブ内に保持し、「再試行」、コピー、全メモのJSON／Markdown書き出しを使えます。破損・未知形式の保存データは上書きせず、元データのコピー・書き出しも提供します。保存失敗中に閉じるときは保持方法を選べますが、再読込前に必ず本文を救済してください。別端末・別ブラウザ・別サイトアドレスには引き継がれず、プライベート閲覧終了やサイトデータ削除で失われることがあります。JSON取込UIとメモ削除は今回の範囲に含みません。

複数タブのメモはIDで統合します。同じメモが別タブで更新されても入力欄は無言で置き換えず、通知します。入力欄と保存内容が異なる場合、「制作に送る」は投稿画面を開かず、一覧の「編集」から新しい内容を確認するよう案内します。そのまま本文・種類・場面を編集して保存すると、その入力内容が新しい版になります。共有だけでは本文・種類・場面を上書きしません。投稿画面を開く間に別の保存が入った場合は、クリック時の入力内容を共有したことと、端末の新しい保存内容を変更していないことを表示します。

## まだ入れていないもの

カードを選ぶと、実際の速度と登録順で仮の命令がACTION ORDERへ入り、盤面は「この命令の直前」へ切り替わります。早い敵の移動、先行命令による撃破や状態変化、マス占有を反映した合法対象だけが光ります。結果欄は変化を種類ごとに集約し、タイムラインで行動を選ぶと全対象の詳細を確認できます。予告の輪郭は、その時点で未解決かつ有効な敵行動だけを表示します。

速度帯には役割があります。FASTは敵より先に守る・止める・逃がす命令、NORMALは敵FASTの移動後に迎撃・離脱する命令、SLOWは敵NORMAL後の配置へ大きく返す／次の攻撃を準備する命令です。現在はFAST 6枚、NORMAL 4枚、SLOW 2枚です。「踏み込み斬り」と「離脱射撃」はNORMAL、「狩人の印」はSLOWで次の攻撃+3、「連鎖火花」はSLOWで本体3・上下左右の隣接敵に2ダメージです。どのカードも移動命令へ変換した場合は元の速度に関係なくFASTになります。

敵が「生命吸収（吸命）」で実際に回復すると、その回復量だけ同じターン中の帯電になります（上限2）。盤面では固定位置の稲妻形に完全な現在値を表示します。満タンへの空振り回復では増えず、ターン終了時に消えます。「連鎖火花」は本体3ダメージを変えず、対象の上下左右にいる生存敵への各2ダメージへ帯電値を加算します。連鎖先がいれば帯電を消費し、いなければ消費せず「連鎖先なし（帯電ボーナスなし）」と表示します。狩人の印+3は本体だけに乗り、斜めの敵には連鎖しません。本体を撃破しても、攻撃直前に上下左右へいた敵への連鎖は発生します。

分岐マップ、仲間の加入、戦闘後のカード選択、強化、装備、支援関係、セーブ機能は、戦闘の核を検証してから追加する想定です。
