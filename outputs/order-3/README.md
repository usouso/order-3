# ORDER//3 — ACT 27

3人の固有カード計12枚を混ぜた共有デッキで、敵の予告を見て1～3命令を組む戦術ゲームです。`index.html`をブラウザで開けば遊べます。感想メモを継続保存するには、同じブラウザ・同じHTTP(S)アドレスを使ってください。ファイルを直接開いた場合の保存範囲はブラウザによって異なります。

## 操作と予測

味方列または盤面の味方を選ぶと、その味方の手札中の固有カードが先に表示されます。カードを選び、盤面で対象を指定して命令を登録します。手札から直接選ぶ従来の操作も使えます。各カードは代わりにALT移動として消費でき、生存味方を空き隣接マスへ1歩動かします。味方を選んだだけではカードを消費しません。

「作戦実行」で命令と敵行動を「味方①→敵①→味方②→敵②→味方③→敵③」の順に交互に解決します。味方の番号は登録順です。敵の番号①②③はターン開始時に行動ごとに決まり、画面上段「敵の命令」に計画前から表示され、計画中も解決中も変わりません。命令のない枠は飛ばします。命令1件なら「味方①→敵①→敵②→敵③」です。ターン開始時に撃破済みの敵の番号は空きになり、他の敵の番号は繰り上がりません。命令1件から実行できます。全敵を倒せば勝利、全味方が倒れれば敗北です。手札は次ターンに5枚まで引き、山札が空なら捨て札を混ぜます。

画面は幅によらず上から「敵の命令 → フィールド → 行動予測 → 自分の手札」の順です。行動予測は「味方n／敵n」の3組を解決順に並べ、空いた枠は「未登録」「なし」と表示します。カードを選ぶと、次に入る味方枠の直前（味方①～n と敵①～n を解決した直後）に戻して合法対象を示し、登録後は全行動後の状態を予測します。行動カードを選べばその行動直後、最終予測を選べば全行動後を確認できます。最終予測はターン末の解除・ドロー前です。射程外や対象撃破などの取消理由も表示します。登録済みの中間命令が予測上取消なら、そのカードだけ手札へ戻せます。戻すと後ろの命令は一つ前の番号に繰り上がり、解決が敵1行動ぶん早くなります。最後の命令は「1手戻す」で戻します。

盤面の味方や敵予告を選ぶとHP、状態、対象、移動経路を読めます。「割って入る」は登録前に対象別の移動経路と装甲増加を仮表示し、仮表示だけでは登録されません。初回案内、Helpの全技説明、キーボード操作も利用できます。

## 共通戦闘規則

距離は上下左右のマス数です。敵の対味方行動はターン開始時に最寄りの生存味方を固定し、同距離ならHPが低い方、さらに同じならルーク→ヴェイル→イオナの順です。予告後に狙い直しません。解決時点で使用者が戦闘不能なら不発で、敵が別の行動や対象へ切り替えることはありません。味方の射程は解決時の距離で判定します。壁と生存駒を越えられず、足止めでも移動できません。移動できなくても既に隣接なら攻撃できます。

一時状態は装甲・足止め・目印の3つだけです。装甲は加算でき、HPより先にダメージを吸収します。足止めは移動を止めます。敵に付いた目印は、次の味方由来ダメージを+3し一回で消費します。装甲で全吸収されても消費し、重ねても増えません。3状態はいずれもターン末に消え、HPと位置は残ります。

持ち主が戦闘不能の手札は全員共通の「遺志：装甲」となり、距離無制限で生存味方一人へ装甲+2を付けます。登録後に持ち主が倒れた固有技は遺志へ自動変換されません。

火種の罠は敵が踏んだら一回だけ3ダメージを与え、その移動イベントの残り歩数を止めます。罠は消え、未発動でもターン末に消えます。災印は予告された十字マスへ固定され、次ターンの起爆時にそのマスの生存味方へ各4ダメージを与えます。起爆後、または詠唱師が倒れて起爆が取消になった時も災印は消えます。

## 12枚の技と敵の予告

カードは名前・対象と射程・効果一文を表示します。速度の区別はなく、登録した味方枠で解決します。12枚の全文、9種の敵行動、ALTと遺志はHelp「全ての技の説明」で読めます。ルークは接近攻撃、割って入る、装甲+5、装甲解除攻撃。ヴェイルは射撃、足止め、離脱、目印。イオナは中心3と隣接敵各2の連鎖火花、位置交換、装甲+3、火種の罠です。

敵は3ターン周期で行動し、括弧内が敵の番号です。追跡獣は忍び寄る（2歩接近+2ダメージ、敵①）、飛びかかり（3歩接近+4ダメージ、敵①）、息を整える（1歩接近+2ダメージ、敵③）。城壁兵は装甲支援（詠唱師または自身へ装甲+4、敵②）、盾の圧力（1歩接近+3ダメージ、敵②）、構え（自身へ装甲+6、敵①）。詠唱師は災印を刻む（十字の災印設置、敵③）、災印起爆（次ターンの起爆、敵③）、生命吸収（2ダメージ後に自身を最大2回復、敵②）。敵予告は盤面上の固定対象と座標を確認できます。

## プレイログ（端末内の記録）

戦闘ごとに乱数シードを決め、山札のシャッフルはそのシードだけで決まります。命令を一度実行した戦闘は、シード、各ターンの手札・山札と捨て札の順番・敵予告・登録命令・結果、考えた時間、画面幅の区分をこのブラウザの端末内に記録します。保存は最大20戦・合計150万文字までで、上限を超えると古い記録から消えます。端末に保存できない場合もゲームは止まらず、このタブの中だけで記録を続けます。プレイログはゲームから送信しません。再読込や再戦では戦闘を再開せず、新しいシードの新しい記録になります。記録の確認・ひとことコメント・ファイルへの書き出しは、現在の画面にはまだありません。

## 感想メモ


上部または表示中の画面内の「感想メモ」から、感想・改善案・不具合を記録できます。本文を入力して約500ms後に、このブラウザへ下書きを自動保存します。「端末に保存」で即時保存でき、保存したメモの「編集」から同じメモを更新できます。再読込や再戦でも残ります。空白だけの本文は新しい保存件数に含めません。既存メモの本文を空にしても、以前の保存内容は削除しません。

「この場面を添付」は任意です。開いた時点のTURN、選択カード、最大3命令、予測段階、版名「ACT 27」だけを添えます。移動経過は添付しません。保存した場面は「現在の場面に更新」を押すまで変わりません。メモを開閉してもカード選択や命令はそのままで、作戦解決中も通常どおり処理が進みます。勝敗画面からも同じメモを利用できます。キーボードではTabで移動し、Escapeで閉じると元のボタンへ戻ります。

端末への保存だけでは制作側へ送信されません。一件の「制作に送る」を押し、送る全文・種類・場面の有無を確認してください。「フォームを開く」で[ORDER//3 試遊メモ](https://docs.google.com/forms/d/e/1FAIpQLSdlXmRTYuIASUMyvcYxg_OnziKKaA9I_T5FXlRXq9u3sJYs8g/viewform)が別タブで開きます。ログインせず回答でき、回答は一般公開されません。フォーム内の「送信」を押し、完了画面を確認してください。フォームを開いただけでは回答は届きません。ゲーム側は送信完了を検知できません。

長文も切り捨てず保存します。短い全文はフォームの「送るメモ」へ事前入力します。長くてURLが1800文字を超える場合は「送る全文をコピー」してフォームの一つの欄へ貼り付けてください。全文をUTF-8テキストで書き出すこともできます。確認欄は選択して手動コピーできます。従来のMarkdown/JSON書き出しも残しています。

端末へ保存できない場合は本文をこのタブ内に保持し、「再試行」、コピー、全メモのJSON／Markdown書き出しを使えます。破損・未知形式の保存データは上書きせず、元データのコピー・書き出しも提供します。保存失敗中に閉じるときは保持方法を選べますが、再読込前に必ず本文を救済してください。別端末・別ブラウザ・別サイトアドレスには引き継がれず、プライベート閲覧終了やサイトデータ削除で失われることがあります。JSON取込UIとメモ削除は今回の範囲に含みません。

複数タブのメモはIDで統合します。同じメモが別タブで更新されても入力欄は無言で置き換えず、通知します。入力欄と保存内容が異なる場合はフォームを開かず、一覧の「編集」から新しい内容を確認するよう案内します。そのまま本文・種類・場面を編集して保存すると、その入力内容が新しい版になります。確認後に別タブで変わった場合も、もう一度内容を確認してください。旧GitHub投稿画面を開いた記録は保存データに残しますが、フォームの送信完了とは扱いません。
