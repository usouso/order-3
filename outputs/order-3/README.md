# ORDER//3 — ACT 32

3人の固有カード計12枚を混ぜた共有デッキで、公開された敵の手札と命令を見て1～3命令を組む戦術ゲームです。`index.html`をブラウザで開けば遊べます。プレイログとひとことコメントを端末に残すには、同じブラウザ・同じHTTP(S)アドレスを使ってください。ファイルを直接開いた場合の保存範囲はブラウザによって異なります。記録はゲームから送信せず、書き出したファイルを送ったときだけ届きます。

## 操作と予測

盤面の味方、または右の列の「味方一覧から選ぶ」で味方を選ぶと、その味方の手札中の固有カードと「1マス移動」が右の列の上に表示されます。カードを選び、盤面で対象を指定して命令を登録します。手札から直接選ぶ従来の操作も使えます。各カードは代わりにALT移動として消費でき、生存味方を空き隣接マスへ1歩動かします。味方を選んだだけではカードを消費しません。

「作戦実行」で命令と敵行動を「味方①→敵①→味方②→敵②→味方③→敵③」の順に交互に解決します。味方の番号は登録順です。敵の番号①②③は、ターン開始時に敵の手札から選ばれた札に付き、画面上段の敵の手札に計画前から表示され、計画中も解決中も変わりません。命令のない枠は飛ばします。命令1件なら「味方①→敵①→敵②→敵③」です。敵の命令は後ろの番号から埋まり、命令が2枚なら敵②③、1枚なら敵③です。命令1件から実行できます。全敵を倒せば勝利、全味方が倒れれば敗北です。手札は次ターンに5枚まで引き、山札が空なら捨て札を混ぜます。

画面は、上に敵の手札5枚、左上に敵の山札・捨て札の枚数、左に行動予測と自分の山札・捨て札、中央にフィールド、右に選んだ味方やカードの詳細と作戦実行、その下に手札を置きます。横長の画面で遊ぶ前提で、画面の幅や向きによって配置は変わりません。登録した命令は手札の列に「味方①」の印で残ります。行動予測は「味方①→敵①→…→敵③」の6枠を上から解決順に並べ、空いた枠は「未登録」「なし」と表示します。高さ700px以上の画面では各枠の2行目（対象と予測）を折り返して全文表示し、それより低い画面では1行目だけを表示し、対象と予測は枠を選んだときの右の列と読み上げで読めます。カードを選ぶと、そのカード・右の列・行動予測の枠に同じ「味方n」を表示し、次に入る味方枠の直前（味方①～n と敵①～n を解決した直後）に戻して合法対象を示します。登録後は全行動後の状態を予測します。行動カードを選べばその行動直後、最終予測を選べば全行動後を確認できます。最終予測はターン末の解除・ドロー前です。射程外や対象撃破などの取消理由も表示します。登録済みの中間命令が予測上取消なら、右の列からそのカードだけ手札へ戻せます。戻すと後ろの命令は一つ前の番号に繰り上がり、解決が敵1行動ぶん早くなります。最後の命令は「1手戻す」で戻します。

右の列は、押して使う操作（手札へ戻す、選んだ味方の技と1マス移動、カードの「固有技として使う」「移動命令に変換」「選択解除」、「割って入る」の対象登録）を上に、説明・効果詳細・味方の状態・戦闘ログを下に置きます。列の中に続きがあるときは、下端に「続き」を表示します。3件目の命令を登録したとき、または選んだ味方に使える命令が残らなくなったときは、味方の選択が外れ、右の列は「全行動後の予測」の表示に戻ります。「手札へ戻す」は味方を選んでいる間も表示します。盤面の駒は、広いマスでは記号・名前・HPを、狭いマスでは記号と現在HPだけを表示します。

上段の敵の手札は、①②③の付いた札を敵①→②→③の順に、その後に使われない札を並べます。使われない札には「未使用」と理由（他の札を優先、同じ名前を使用、この敵は2枚使用、命令数の上限、災印が残っている、災印が無い、近づけない）、撃破済みの敵の札には「撃破済み」を表示します。①②③の札を押すと行動予測の同じ敵の枠と同じ表示（移動経路と選ばれた理由）になり、使われない札を押すと右の列で理由と評価を読めます。選んでいる敵の枠と上段の札には同じ点線の印が付きます。狭い画面では札名を省略し、全文は右の列と読み上げで読めます。

盤面の味方や行動予測の枠を選ぶと、右の列でHP、状態、対象、効果詳細を読め、敵の枠では移動経路を盤面に表示します。駒の状態（装甲・足止め・目印）の説明は、マウスを駒に重ねる、キーボードで駒のマスへ移動する、または右の列（選んだ味方の「状態」、カード選択中の「対象の状態」）で読めます。駒をタップ・クリックすると、状態の印の上でも味方の選択や対象の指定になります。「割って入る」は登録前に対象別の移動経路と装甲増加を仮表示し、仮表示だけでは登録されません。初回案内、Helpの全技説明、キーボード操作も利用できます。

## 共通戦闘規則

距離は上下左右のマス数です。敵の札の対象はターン開始時の最寄りの生存味方に固定し、同距離ならHPが低い方、さらに同じならルーク→ヴェイル→イオナの順です。選び直さず、災印も予告座標に固定します。解決時点で使用者が戦闘不能なら不発で、敵が別の札や対象へ切り替えることはありません。同じ敵の2枚目の札は1枚目の移動後の位置から行い、1枚目より前にその敵が倒れれば2枚とも取消になり、使われなかった札は繰り上がりません。味方の射程は解決時の距離で判定します。壁と生存駒を越えられず、足止めでも移動できません。移動できなくても既に隣接なら攻撃できます。

一時状態は装甲・足止め・目印の3つだけです。装甲は加算でき、HPより先にダメージを吸収します。足止めは移動を止めます。敵に付いた目印は、次の味方由来ダメージを+3し一回で消費します。装甲で全吸収されても消費し、重ねても増えません。3状態はいずれもターン末に消え、HPと位置は残ります。

持ち主が戦闘不能の手札は全員共通の「遺志：装甲」となり、距離無制限で生存味方一人へ装甲+2を付けます。登録後に持ち主が倒れた固有技は遺志へ自動変換されません。

火種の罠は敵が踏んだら一回だけ3ダメージを与え、その移動イベントの残り歩数を止めます。罠は消え、未発動でもターン末に消えます。災印は予告された十字マスへ固定され、災印起爆の札が使われたときにそのマスの生存味方へ各4ダメージを与えます。災印は起爆まで残り、起爆後、詠唱師が倒れて起爆が取消になった時、詠唱師が戦闘不能のターン末に消えます。

## 12枚の技と敵の手札

カードは名前・対象と射程・効果一文を表示します。登録した味方枠で解決します。12枚の全文、敵の15枚、ALTと遺志はHelp「全ての技の説明」と「敵の手札と命令の選び方」で読めます。ルークは接近攻撃、割って入る、装甲+5、装甲解除攻撃。ヴェイルは射撃、足止め、離脱、目印。イオナは中心3と隣接敵各2の連鎖火花、位置交換、装甲+3、火種の罠です。

敵チームは3体が5枚ずつ持ち込んだ15枚の山札を使います。追跡獣は忍び寄る2枚（2歩接近+2ダメージ）、飛びかかり1枚（3歩接近+4ダメージ）、息を整える2枚（1歩接近+2ダメージ）。城壁兵は装甲支援2枚（詠唱師または自身へ装甲+4）、盾の圧力2枚（1歩接近+3ダメージ）、構え1枚（自身へ装甲+6）。詠唱師は災印を刻む1枚（十字の災印設置）、災印起爆2枚（災印上の味方へ各4ダメージ）、生命吸収2枚（2ダメージ後に自身を最大2回復）。

敵は毎ターン5枚引いて公開し、ターン開始時の盤面で点の高い札から最大3枚を選びます。同じ名前は1枚、1体2枚まで、命令数は生存している敵の数まで（3体で3、2体で2、1体で1）で、撃破済みの敵の札は山札に残り、手札に来ても使えません。順番は守り→攻撃→災印、同じ種類は点の高い順で、枚数が少ないときは敵③から埋めます。点は、撃破できる攻撃+100、届く攻撃はダメージ×10（生命吸収は回復×5を加算）、災印起爆は災印上の味方1人につき40で、その中にHP4以下の味方がいれば+100（誰もいなければ3）、守る相手の5マス以内に味方がいる守りは装甲×5（いなければ2）、災印を刻むは十字マスの味方1人につき15（災印が残っていれば使わない）、届かない接近は5＋歩数です。敵はプレイヤーの計画を見て選び直しません。ターン末には使った札も残りも捨て札へ送り、山札が空なら混ぜます。15枚を5枚ずつ引くので、3ターンで全15枚が一度ずつ出ます。

## ひとことコメントとプレイログ

戦闘ごとに乱数シードを決め、味方と敵の山札のシャッフルはそのシードだけで決まります（敵の山札は別の乱数列で混ぜます）。命令を一度実行するかコメントを記録した戦闘は、シード、各ターンの手札・山札と捨て札の順番、敵の手札・山札と捨て札の順、敵の命令・登録命令・結果、考えた時間、画面幅の区分をこのブラウザの端末内に記録します。以前の版の記録（ACT 29以前の形式を含む）も端末内に残り、書き出す内容の確認で一覧・コメントの削除・書き出しができますが、再生にはその版の製品が要ります。端末内の保存は最大20戦・合計150万文字・1戦60ターン・1戦50コメントまでです。上限を超えると、コメントの無い古い記録と、書き出した後に変更の無い古い記録から消えます。保存量が上限の8割を超えると、ダイアログで知らせます。端末に保存できない場合もゲームは止まらず、このタブの中だけで記録を続けます。別のタブの書き出し画面でコメントを削除したり記録を書き出したりすると、そのランを遊んでいるタブにも反映されます。確認画面を開いた後に別のタブでそのコメントが変わっていた場合は削除しません。書き出しの途中で記録が変わったランは、ファイルに入らなかった内容があるため書き出し済みにしません。記録の保存、コメントの削除、書き出し済みの記録はランごとの排他ロック（Web Locks）の中で端末の最新の記録に対して行うので、複数のタブでほぼ同時に操作しても互いの内容を消しません（Web Locksが使えないブラウザでは書き出し画面で注意を表示します）。書き出しと削除は一つのタブで行うのが確実です。新しいターンとコメントは上限の1,000文字手前まで保存し、残りは書き出し済みの記録と削除に使います。再読込や再戦では戦闘を再開せず、新しいシードの新しい記録になります。以前の戦闘は「未決着」などとして残ります。

右上（勝敗画面などが表示中はその画面内）の「ひとこと」から、気になった時点で140字までのひとことコメントを記録できます。開いた時点のTURN、計画中・作戦解決中・勝敗、選択カード、登録命令、予測段階をコメントに添えます。作戦解決中の行動や行動予測で選んだ行動は、画面と同じ「味方①」「敵②」の番号で表示します（敵の番号はそのターンに敵の手札から確定した命令の番号です）。Enterか「記録する」で記録すると、ダイアログを閉じて元のボタンへ戻ります。日本語入力の変換確定のEnterでは記録しません。作戦解決中に開いても解決は止まりません。Escapeで閉じます。

「ログを書き出す…」で、書き出す内容を確認してから `order3-YYYYMMDD-HHMM.order3log` を書き出します。確認画面では書き出すランを選び、コメントを削除でき、ファイルの中身（JSON）をすべて表示できます。ファイルはgzip圧縮したJSONです。圧縮できないブラウザーでは圧縮せずに書き出し、ファイルを作れない場合は全文をコピーできます。含むものはゲーム版、乱数シード、各ターンの記録、考えた時間、画面幅の区分、コメント本文です。名前、メールアドレス、端末やブラウザーの情報、位置、正確な時刻は含みません。

ゲームからは何も送信しません。書き出したファイルを制作者に送ったときだけ届きます。以前の感想メモがこの端末に残っている場合は、件数を表示し、書き出すファイルに一緒に含められます。以前の感想メモの保存データは読むだけで、変更も削除もしません。別端末・別ブラウザ・別サイトアドレスには引き継がれず、プライベート閲覧の終了やサイトデータ削除で失われることがあります。
